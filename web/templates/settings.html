How to send recordings automatically 
curl -H "Authorization: Bearer vt_…" \
  -F file=@"Meeting 2026-09-30.m4a" \
  -F preset=accuracy \
  -F source=phone \
  {{ request.host_url }}api/v1/jobs

# optional fields: profile_id, language, prompt, hotwords, title,
#   recorded_at (ISO time), options (JSON of any setting), on_duplicate=new
# check progress:  GET {{ request.host_url }}api/v1/jobs/<id>?text=1

Android: HTTP Shortcuts or Tasker "HTTP Request" with a multipart file field named file. iPhone: Shortcuts → "Get Contents of URL" (POST, Form, field file) in a Share-sheet shortcut. The same file sent twice (from two devices) is recognised by its SHA-256 and not transcribed twice.
